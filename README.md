# Pedometer Pro support website

Public, static support and privacy pages. The app source code remains in a separate private repository.

- Support: https://smallpotatoes-collab.github.io/pedometer-pro-support/
- Privacy policy: https://smallpotatoes-collab.github.io/pedometer-pro-support/privacy.html

GitHub Pages serves the root of the `main` branch. No JavaScript, third-party fonts, analytics, or build dependencies are included.

## Maintenance

Edit `index.html` for support, `privacy.html` for the policy, and `styles.css` for presentation. Push to `main` to publish updates.

The owner selected `goodmeatsoftware@gmail.com` as the current public contact. Confirm that inbox is active and monitored before App Store submission. To change it, update every occurrence in both HTML pages and this README. Keep privacy disclosures aligned with app, website, and support practices; update the policy date when the policy changes.

These pages supply website URLs, not a completed App Store submission. Add the policy link to the app and complete remaining release requirements separately.
